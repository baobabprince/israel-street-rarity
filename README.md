# נדירות שמות רחובות בישראל

ניתוח אינטראקטיבי של שמות רחובות ייחודיים בכל עיר בישראל.

## האתר החי
**https://baobabprince.github.io/israel-street-rarity/**

## מה יש כאן
- מדדי נדירות משוקללים (1/n ולוגריתמי)
- השוואה בין ערים ערביות ליהודיות
- מתאמים עם אוכלוסייה, אשכול חברתי-כלכלי ושנת ייסוד
- טבלה אינטראקטיבית עם סינון ומיון
- גרפים

## מקורות
- רשות האוכלוסין וההגירה — רשימת רחובות ישראל (נובמבר 2026)
- הלמ״ס — קובץ יישובים

## מתודולוגיה בקצרה
1. הסרת רחובות מספריים בלבד
2. נרמול שמות (קידומות, ה׳ הידיעה, שמות אישים)
3. משקל נדירות לוגריתמי לפי מספר היישובים שבהם השם מופיע
4. סכום וממוצע לכל עיר
