# נדירות שמות רחובות בישראל

דשבורד אינטראקטיבי + צינור נתונים אוטומטי המודד עד כמה שמות הרחובות בכל עיר ומועצה מקומית בישראל ייחודיים לה או משותפים ליישובים רבים אחרים.

## אתר (GitHub Pages)
https://baobabprince.github.io/israel-street-rarity/

## הרצת עדכון נתונים
1. לכו ל-**Actions** → **Update street rarity data** → **Run workflow**
2. הסקריפט מוריד את רשימת הרחובות (רשות האוכלוסין) ונתוני הלמ״ס מ-data.gov.il, מנקה ומנרמל, מחשב מדדי נדירות וכותב `data.json`, `data.min.json`, `examples.json` ו־`meta.json`.
3. אחרי שה-Action מסתיים — רעננו את האתר.

## הרצה מקומית ובדיקות
```bash
pip install -r requirements.txt
python scripts/build_data.py
pytest
```

## מבנה הפרויקט
- `scripts/normalize.py` — לוגיקת ניקוי מבני, איחוד שמות אישים הפוכים, וסיווג מגזרי לפי הלמ״ס
- `scripts/build_data.py` — הורדת נתונים, נרמול, הסרת כפילויות וחישוב מדדי נדירות
- `scripts/build_mazal_aliases.py` — בניית מפת כינויים מבוקרת מ-Wikidata (מזהי J9U / מז״ל) + עקיפות ידניות
- `data/mazal_aliases.json` — מפת כינויים מבוקרת ומנורמלת
- `tests/test_normalize.py` — בדיקות יחידה ובדיקות תקינות מתמטית לנתונים
- `.github/workflows/update-data.yml` — Action שנתי (1 בינואר) + הפעלה ידנית
- `index.html` — דשבורד אינטראקטיבי (Chart.js)

## מתודולוגיה
- **סינון רעש**: הסרת רשומות `סמל_רחוב = 9000` (שורת ברירת מחדל המכילה את שם היישוב עצמו) והסרת רחובות מספריים בלבד.
- **נרמול מבני**: הסרת ניקוד, אחידות גרש/גרשיים ומקפים, הסרת קידומות דרך ושכונה (`רחוב`, `שדרות`, `שדרת`, `דרך`, `סמטה`/`סמ`, `משעול`, `מבוא`, `רחבת`, `נתיב`, `מעגל`, `שכ`, `ש ` וכו׳), ללא הסרה אוטומטית של ה׳ הידיעה.
- **איחוד זהויות**: איחוד שמות אישים דו-מילתיים הפוכים (`בגין מנחם` ↔ `מנחם בגין`) + מפת כינויים מבוקרת (`data/mazal_aliases.json`).
- **הסרת כפילויות בתוך יישוב**: כל שם מנורמל נספר פעם אחת בלבד בכל יישוב לפני חישוב ממוצע וסכום הנדירות.
- **סיווג מגזרי רשמי (למ״ס)**: מבוסס על שדה `דת יישוב` הרשמי של הלמ״ס (`1` יהודי, `2` ערבי — כולל דרוזים וצ׳רקסים לפי הגדרת הלמ״ס, `4` מעורב) לצד אחוז אוכלוסייה ערבית.
- **נוסחאות משקל**: `1/log₂(1+n)` (לוג) ו־`1/√n` (שורש), כאשר `n` הוא מספר היישובים בארץ בהם מופיע השם.
